How to read this report

    

      

        
This lab compares conditions, not winners. Each row is a Stage A benchmark cell: one document and model analyzed from its frozen canonical transcript. Stage T ingestion is run separately and produces the transcript fixtures; Stage A does not dispatch PDF parser or native-file arms. Unsupported combinations are marked "skipped," not scored as failures.

        
Parser fidelity (diagnostic) belongs to Stage T and compares a parser transcript with local PDF text when available. Scanned pages have no embedded text layer, so the frozen transcript and page map are the ground-truth artifacts to inspect. Parser failure or a transcript shorter than 100 characters prevents Stage A.

      

      

        
Analysis quality is the answer table. Every Stage A arm receives the same canonical text; valid JSON is measured among answered calls. Quote grounding checks claims against that text. Gold scores appear only for verified facts; missing gold is not a zero.

        

          What does the judge do?
          
An optional LLM judge from a different model family compares two answers for the same document pairwise (swapping positions to neutralise order bias), looking at completeness, correctness, and whether the figures survive. It is a triage signal only: it never feeds the benchmark scores and never picks a winner.

          
Calibration compares those judge preferences against your own usable / not-usable verdicts. Agreement shows how much to trust the judge; it does not overrule either the human review or the deterministic metric scores.
