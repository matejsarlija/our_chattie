## Review Checklist

For each review round, validate:
1. Running + rich events: scanability and noise level
2. Running + sparse events: confidence without over-chrome
3. Completed + result: result readability takes priority
4. Failed + escalation: error salience without full-page alarm state
5. Mobile layout: no clipped controls, no unusable density
